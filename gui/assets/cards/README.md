# Card images

The 32 belote cards, taken from a modern French tarot deck, *Deck of French
Tarot playing cards*, published in the public domain (CC0) on freesvg.org:
<https://freesvg.org/deck-of-french-tarot-playing-cards>

The PNG renderings come from the `jeuxcartes` LaTeX package by Cédric Pierquet,
which redistributes that deck as `CaJ-TaroTv1-*.png` files:
<https://github.com/cpierquet/latex-packages/tree/main/jeuxcartes>

Files are 250 by 481 pixels, named `<suit>_<value>.png` with suit in heart,
spade, diamond, club and value 01 (ace), 07 to 10, 11 (jack), 13 (queen) and
14 (king). The tarot deck's knights (12) are not part of a belote deck.
